## CZSC 源字段如何进入训练

下面的字段组对日、周、月均适用。个股日线前缀是 `czsc_`，周/月是 `czsc_weekly_`、`czsc_monthly_`；指数前缀继续包含指数别名和 `calc_daily_czsc_structure`。

| 业务源字段 | 个股表达 | 行业/大盘表达 |
|---|---|---|
| `period_complete`、`source_bar_valid` | 保留布尔值 | 0/1 |
| `status` | `invalid_source_bar/no_finished_bi/insufficient_bis_for_zs/no_valid_zs/ok` 类别，缺快照另标识 | 同五种状态编码 0～4；未知或 NULL 留缺失 |
| `available_finished_bi_count`、`recent_bi_count` | 数量 | 数量 |
| `last_bi_direction` | `up/down/missing` 类别，另计算有方向笔幅 | up=1、down=−1，缺失不补方向 |
| `last_bi_start_date/end_date` | 两日期的日历年龄、持续日历天数、窗口足够时的交易日长度 | 两日期的日历年龄和持续日历天数 |
| `last_bi_high/low/mid` | `100 × (收盘/锚点−1)`、笔幅 | `100 × 锚点/指数收盘` |
| `latest_zs_start_date/end_date` | 同上，转换为中枢年龄/持续时间 | 同上 |
| `latest_zs_bi_count` | 中枢笔数 | 笔数 |
| `latest_zs_zg/zd/zz` | 收盘距离、中枢宽度、收盘所在区域类别 | 相对指数收盘比例 |
| `recent_peak_date/high` | 前高可用标志、年龄、收盘距离 | 日期年龄、相对收盘比例 |
| `post_peak_first_bear_date` | 定价线年龄 | 日期年龄 |
| `post_peak_first_bear_open/high/low/close` | 定价线/首阴收盘距离、首阴实体和振幅 | 相对指数收盘比例 |
| `post_peak_first_bear_missing` | 保留布尔值 | 0/1 |

周/月只加载选股日额外字段，不扩大全市场一年历史 CZSC 投影。日线原有突破、回踩、缩量和失效生命周期因子保留；周/月、行业和指数本次接入的是完整的源表快照及其语义转换，未复制日线生命周期历史计算。这是额外复合因子的范围选择，不是源字段漏读。

周/月结构常跨数年，不能用一年行情窗口声称算出完整交易日长度。窗口覆盖不足时交易日计数留空；日历天数仍完整。周/月 8 个补充交易日计数列可在全训练窗全空时被记录并剔除，快照、日历天数等其他输入继续接受覆盖检查。

## 关联、版本和防遗漏约束

- 大盘共 9 个：上证50、沪深300、中证500、国证2000、创业板指、科创50、北证50、中证A50、中证红利。
- 成分与权重只读取数据库 `index_weight` 中不晚于选股日的快照。非成分股已有上下文数值置零；源端没有的数据继续缺失。
- 行业仍按 `index_sw_member` 的入/出日期区间匹配申万二级行业；衍生来源限定 `index_idx_factor_pro`，没有恢复旧 THS 口径。
- 价格锚点与个股收盘价同时重定前复权基准；日期、状态、笔数不能乘复权倍率。
- 单元测试逐字段检查四张指数源表的有意排除集合，新增业务字段必须明确处理；补充了数据库投影执行、缓存版本拒绝、价格基准、方法间导出、Python 类型与 dataset 保留测试。
- 版本升为 v11/schema 21，阻止旧因子或缺少周/月快照的 prepared 缓存静默进入新流程。
